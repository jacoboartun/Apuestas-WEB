# Apuestas-WEB

Bienvenido al repositorio de **Apuestas-WEB**, un proyecto de plataforma web para juegos de azar y apuestas.

## Estructura del Proyecto

- `frontend/` - Código y recursos de la interfaz de usuario.
- `backend/` - Lógica del servidor y base de datos.
- `css/` - Hojas de estilo para la aplicación.
- `js/` - Scripts de cliente.
- `index.html` - Punto de entrada principal de la aplicación web.

## Tecnologías

Proyecto desarrollado utilizando tecnologías web estándar (HTML, CSS, JavaScript) y estructura cliente-servidor.
